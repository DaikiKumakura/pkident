# pkident

Structural and practical identifiability for pharmacokinetic and pharmacodynamic ODE models.

**Status: in development (not released).** Milestone S2 is complete: `pkpd_model()` reads rxode2 models, doses and known input signals, and all reference models load. Identifiability decisions are not implemented yet.

See `SPEC.md` for the specification and `validation/reference-models.md` for the reference models and their expected results.
